# fin-account · Карьер-менеджер

Приложение для малого карьера: мастер фотографирует первичные документы на телефоне, ИИ распознаёт строки, бухгалтер проверяет спорные позиции в веб-очереди и одной кнопкой отгружает данные в учёт, скачивая выгрузку одним CSV-файлом по колонкам шаблона. Из отгруженных документов строятся отчёты ОПиУ и ДДС.

Доступ разграничен ролями: Наблюдатель (только просмотр), Редактор (просмотр и редактирование), Администратор (плюс управление пользователями). Регистрация, пользователи и сессия хранятся в браузере (localStorage), без бэкенда.

Реализовано по дизайн-хэндоффу `design_handoff_karier_manager` (hi-fi экраны).

## Стек
- Frontend: React + Vite (`web/`), шрифты Golos Text / IBM Plex Mono, иконки Lucide
- Backend-логика: Python + openpyxl (`src/`) — генерация выгрузки по шаблону

## Структура
- `web/` — веб-интерфейс: экран регистрации/входа, очередь документов, отчёты ОПиУ/ДДС, категории, шаблоны, настройки (выгрузка CSV + управление пользователями); адаптивные мобильные экраны (съёмка, очередь, отчёты) при ширине < 768px
- `src/` — Python: `export_xlsx.py` (выгрузка по маппингу «шаблон_учёт.xlsx»), `main.py` (читает вход из `data/documents.json`)
- `data/` — входные Excel/CSV файлы (в .gitignore)
- `output/` — результаты (в .gitignore)

## Запуск

Веб-интерфейс:
```
cd web
npm install
npm run dev
```

Выгрузка в .xlsx (вход — `data/documents.json`):
```
py src/main.py
```

Интерфейс стартует пустым (без демо-данных): очередь, отчёты и категории наполняются по мере работы. Первый зарегистрированный пользователь становится администратором. Выгрузка отгруженных документов скачивается кнопкой «Скачать .csv» (Настройки / Отчёты). Python-модуль — кандидат на бэкенд реальной выгрузки.

## Конфигурация
Скопировать `.env.example` → `.env` и заполнить пути.
